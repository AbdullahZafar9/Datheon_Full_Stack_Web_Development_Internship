About me

I build high-performance web systems and multi-tenant applications. The work spans Next.js and React on the client, TypeScript across the stack, and real-time backends on Supabase — PostgreSQL with row-level security and WebSockets.

Recent projects shipped as production-ready SaaS and editorial sites: client-side motion with scroll choreography, cloud media pipelines aimed at fast image delivery, and data models that keep each tenant’s records isolated.
